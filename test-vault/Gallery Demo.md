A standalone note demonstrating the multi-image infobox: three images of different aspect
ratios share one fixed-height frame (letterboxed via `object-fit: contain`), with hover
chevrons, a slide counter, and a click-to-zoom lightbox. A single image or a one-item list
renders exactly as before — no chrome — but is still clickable to zoom.
